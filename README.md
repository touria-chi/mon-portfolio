# Portfolio — Touria Chiguer

React + Vite + React Router (HashRouter, compatible GitHub Pages).

## Lancer
```
npm install
npm run dev      # développement
npm run build    # production (dossier dist/)
```

## Personnaliser
- Tout le contenu est dans `src/data.js` (textes, liens GitHub, liens entreprises, certifs).
- Images dans `public/images/` :
  photo.jpg, salesflow.png, cabinet.png, ecoride.png, codearena.png, agora.png,
  cert-java.png, cert-sql.png, cert-yanecode.png, badges-trailhead.png
- Cherchez les `TODO` dans `src/data.js` : liens à compléter (dépôts GitHub, Trailhead, LinkedIn, site Nexotek, CV).
